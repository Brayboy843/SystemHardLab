## System Hardening Walkthrough

### Objective

Improve the security of a Windows workstation by applying basic system hardening best practices.

### Environment

- Windows 11
- Local Security Policy
- Microsoft Defender
- Windows Firewall

### Steps

#### Step 1: Install Updates

- Check for Windows Updates.
- Install all available security patches.
- Restart the system if required.

#### Step 2: Enable Microsoft Defender

- Verify real-time protection is enabled.
- Run a full system scan.

#### Step 3: Configure Windows Firewall

- Confirm Windows Firewall is enabled.
- Verify Domain, Private, and Public profiles are active.

#### Step 4: Apply Password Policies

- Configure password complexity.
- Set minimum password length.
- Configure password expiration policies.

#### Step 5: Disable Unnecessary Services

- Review running services.
- Disable unused or unnecessary services.
- Remove unused software.

#### Step 6: Verify Security Settings

- Confirm antivirus is active.
- Verify firewall status.
- Test system functionality after changes.

### Skills Demonstrated

- Windows Security
- Endpoint Hardening
- Vulnerability Reduction
- Security Best Practices
- System Administration

### Outcome

Successfully hardened the Windows workstation by reducing its attack surface and applying essential security controls.
